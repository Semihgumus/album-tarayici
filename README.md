# Albüm Tarayıcı

Eski fiziksel fotoğrafları telefonla çekip otomatik kırpan, perspektifini düzelten ve siyah-beyaz / renkli olarak iyileştiren tek sayfalık web aracı.

- Adres: https://semihgumus.github.io/album-tarayici/
- iPhone'da Safari ile aç → Paylaş → **Ana Ekrana Ekle**.
- Fotoğraflar cihazdan hiçbir yere gönderilmez; tüm işlem tarayıcıda yapılır.
